# Nepal Rainfall Analysis

An interactive data analysis of 45 years of rainfall data across Nepal (1981–present).

## 🔍 Key Findings

- **Strong monsoon seasonality:** Over 75% of annual rainfall occurs June–September, peaking in July (~134 mm average)
- **Regional variation:** Wettest regions receive ~2.5x more rain than the driest
- **No strong long-term trend:** Yearly rainfall is variable but stable over 45 years
